The tech track is where I go deepest, so here is how a Microsoft 365 workspace gets built from scratch.

Microsoft 365 setup

From “which plan?” to a workspace your team can use

Every business is set up in the same order, so nothing is missed and everyone knows where things live.

  1. Pick the subscription

    Match the Microsoft 365 plan to your team size, tools and budget, so you pay for what you use.

  2. Plan onboarding

    Create users, assign licences and set up a repeatable process for new joiners and leavers.

  3. Set up mailboxes

    Business email on your domain through Exchange, including shared mailboxes where needed.

  4. Build SharePoint sites

    One home for each team, with permissions that match who should see what.

  5. Organise OneDrive

    Clear folder structure and sharing habits, so files stop living in inboxes.

  6. Launch Teams

    Channels for each team and a short walkthrough so people actually use it.
